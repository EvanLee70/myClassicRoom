# 팬클럽 자료 조사 지침 (myClassicRoom · 손열음)

대상: 피아니스트 손열음 (Yeol Eum Son). 오늘 날짜는 2026-10-14입니다.

## 공통 규칙
- WebSearch / WebFetch만 사용합니다(쉘은 외부 사이트 접속 불가). 검색은 70회 이내로 아껴 씁니다(여러 에이전트가 한도를 나눠 씀).
- **사실마다 출처 URL**을 남깁니다. 공식 사이트, 소속사, 음반사, 공연장, 언론 기사, 위키백과 순으로 신뢰합니다.
- 출처끼리 다르면 더 공식적인 쪽을 쓰고 note에 차이를 적습니다. 확인 못 한 것은 넣지 않거나 "확인 필요"로 표시합니다.
- 모든 설명은 **한국어로, 본인 말로** 씁니다. 원문 문장을 옮기지 않습니다(인용은 15단어 미만, 출처당 1회 이하). 한자 금지.
- 사생활(가족, 연애, 주소 등) 중 본인이 공개적으로 밝힌 활동과 무관한 것은 넣지 않습니다. 사진 파일은 수집하지 않습니다.
- 결과는 지정 경로에 Write 도구로 UTF-8 JSON으로 저장합니다. 마지막 응답은 "항목 수 요약 + 경로 + 확인 못 한 것" 몇 줄만.
